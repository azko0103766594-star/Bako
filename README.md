# TEXT PRO

Application web responsive / PWA de nettoyage, transformation, formatage et partage de texte.

## Déploiement Netlify

1. Décompressez le ZIP.
2. Glissez le dossier dans Netlify Drop ou connectez le dépôt Git.
3. Aucun build command n'est nécessaire.
4. Le dossier publié est la racine contenant `index.html`.

## Fonctionnement

- Frontend uniquement pour les fonctions locales.
- `localStorage` pour le brouillon, les préférences et l'historique.
- Compatible téléphone, tablette et ordinateur.
- Boutons de partage vers WhatsApp, Facebook, Instagram et le menu de partage natif.
- Aucun compte utilisateur nécessaire.

## Important

Les fonctions « Améliorer » incluses dans cette V1 sont des transformations locales simples. Une véritable réécriture par IA nécessiterait une API/backend et doit être ajoutée séparément si souhaité.

Pour une future APK Android, cette interface web peut être emballée avec Capacitor ou une autre solution PWA/WebView.
